## Dawn of the Infinite

1. Lockout holding account:
    1. Set difficulty to Mythic
    2. Clear to Deios
    3. Leave
    4. Invite characters on other accounts
2. Other accounts:
    1. Enter dungeon
    2. Check to make sure you're in a 7/8 instance
3. Lockout holding account:
    1. Pass lead to character on other account
    2. Log out?
4. Other accounts:
    1. Kill Deios
    2. Leave

## Firelands > Fandral

1. Lockout holding account:
    1. Set difficulty to Normal
    2. Clear to Fandral
    3. Leave
    4. Set difficulty to Heroic
    5. Clear to Fandral
    6. Leave
    7. Invite druids on other accounts
2. Other accounts:
    1. Enter Firelands
    2. Kill Fandral
    3. Leave
3. Lockout holding account:
    1. Set difficulty to Normal
4. Other account(s):
    1. Enter Firelands
    2. Kill Fandral
    3. Leave
